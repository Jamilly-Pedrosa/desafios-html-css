# 💻 Monitoria Web — Desafios de HTML & CSS

Este repositório reúne desafios propostos durante a **monitoria de desenvolvimento web** do meu curso, com foco na prática dos fundamentos de HTML e CSS.

---

## 📚 Sobre os Desafios

Cada desafio foi pensado para desenvolver uma habilidade específica no front-end, evoluindo de estruturas básicas até a criação de layouts completos.

---

## 🧩 Desafios

### ✦ Desafio 1: Minha Primeira Página

**Objetivo:** Criar uma página HTML completa utilizando a estrutura básica do HTML5.

Aprendi a montar a estrutura base de um arquivo HTML e utilizar tags semânticas essenciais.

---

### ✦ Desafio 2: Cartão de Perfil

**Objetivo:** Estilizar um cartão de perfil usando CSS, praticando seletores, cores, bordas e espaçamento (box model).

Pratiquei estilização com CSS, incluindo cores, espaçamento, bordas arredondadas e sombras.

---

### ✦ Desafio 3: Galeria de Cores

**Objetivo:** Usar Flexbox para organizar elementos lado a lado, criando uma galeria de quadrados coloridos.

Utilizei **Flexbox** para organizar elementos de forma responsiva e criar interações com hover.

---

### ✦ Desafio 4: Menu de Navegação

**Objetivo:** Criar um menu de navegação horizontal usando listas HTML e CSS, com efeito de destaque ao passar o
mouse.

Aprendi a estruturar menus com listas e aplicar estilos interativos com CSS.

---

### ✦ Desafio 5: Layout de Blog

**Objetivo:** Usar CSS Grid para criar um layout clássico de blog com cabeçalho, área de conteúdo, barra lateral e
rodapé.

Utilizei **CSS Grid** para construir um layout com header, main, aside e footer.

---

## 🧠 Aprendizados

Ao longo desses desafios, pratiquei:

* Estruturação correta com **HTML5**
* Estilização com **CSS**
* Uso do **Box Model**
* Organização de layout com **Flexbox**
* Construção de páginas com **CSS Grid**

---

## ➜ Como executar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/Jamilly-Pedrosa/desafios-html-css.git
```

2. Acesse a pasta do projeto:

```bash
cd desafios-html-css
```

3. Abra o arquivo `index.html` de cada desafio no navegador:

* Clique duas vezes no arquivo
  ou
* Use a extensão **Live Server** no VS Code
